# YlTt2025 Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the default favicon with a multi-size, monochrome geometric rabbit mark.

**Architecture:** Keep Next.js's existing root `app/favicon.ico` convention and preserve the vector source at `public/yltt-rabbit.svg`. A small local Node utility mirrors the source geometry, rasterizes it into PNG payloads, and packages those payloads into a standards-compatible ICO file.

**Tech Stack:** Next.js 16 app icon convention, SVG path geometry, Node.js built-ins (`zlib`, `Buffer`), Vitest/project verification scripts.

---

### Task 1: Add the deterministic favicon generator

**Files:**
- Create: `scripts/generate-favicon.mjs`
- Create: `public/yltt-rabbit.svg`

- [ ] **Step 1: Write the generator**

Implement a Node-only generator that draws a `#111111` square with a warm-white rabbit head, long ears, ear cutouts, and face cutouts; encode 16x16, 32x32, and 48x48 RGBA PNGs with Node's built-in `zlib`, and write the PNG entries into an ICO directory at `app/favicon.ico`.

- [ ] **Step 2: Run the generator**

Run `node scripts/generate-favicon.mjs` and verify it reports the three embedded sizes.

### Task 2: Verify the resource and app integration

**Files:**
- Modify: `app/favicon.ico`

- [ ] **Step 1: Inspect the ICO directory**

Read the ICO header and directory entries with a Node inspection command; expect type `1`, image count `3`, and dimensions `16`, `32`, and `48`.

- [ ] **Step 2: Run project checks**

Run `npm run typecheck`, `npm run test`, `npm run build`, and `git diff --check`.

- [ ] **Step 3: Review the final diff**

Run `git status --short` and `git diff --stat` to confirm only the favicon, generator, and the two design documents are included.
